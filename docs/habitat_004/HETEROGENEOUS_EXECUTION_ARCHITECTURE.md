# Heterogeneous execution — candidate assignments, not integration

CPU topology/control, NVIDIA numerical kernels and AMD rendering are plausible
assignments under investigation. Inventory and verified synthetic execution are
separate from complete critical-path cooperation. In004 no renderer consumes the
scientific owner, no full environmental transaction is GPU-resident, and no CPU/GPU
coupling bridge is promoted into an authority. E44–E50 retain their exact dependencies.

A future device owner must stage all inventories/sources/scalars/boundaries and
admissibility/reductions before a single commit, retain old state after device failure,
and produce source/backend/precision-bound checkpoints. Host topology must deliver
a validated layout, never a competing carrier. CPU parallel kernels need deterministic
contribution reduction before state swap. Observer/render packets derive only from
committed state. Evaluate critical-path latency/accuracy and memory, not aggregate
utilization or theoretical FLOP counts. No permanent tuning, driver changes or
intentional exhaustion is authorized or performed.

## Final measurements

Current qualified observations are CPU scientific transactions and separate installed OpenCL arithmetic. No concurrent AMD rendering, CPU/NVIDIA physical partition or device authority bridge exists. Do not infer cooperation from device enumeration. E48/E49 remain NOT RUN.
